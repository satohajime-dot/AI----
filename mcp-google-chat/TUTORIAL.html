Google Chat をつなぐ

秘書（Claude Code）が Google Chat を読めるようにする手順です。上から順に進めてください。終わった段にはチェックを付けておけます。

はじめての方（ほとんどの方はこちら）自分で Google Cloud から鍵を発行します。1回だけの作業です。
ステップ1から・約10分 鍵ファイル（client_secret.json）を受け取っている方組織で発行して配られた場合。Google Cloud の作業は要りません。
ステップ5から・約2分

入れておくと、下の青いボタンがそのプロジェクトの画面へ直接開きます。空のままでも、開いた画面の上部でプロジェクトを選べば同じです。

Google Cloud での作業（ブラウザ）

1

プロジェクトを作る

あなた
プロジェクト作成の画面を開く
  1. 読みたいチャットのアカウントでログインします（会社のチャットなら会社のアカウント）。
  2. プロジェクト名は何でも構いません（例: my-secretary）。作成を押します。
  3. できたプロジェクトの ID（名前の下に小さく出る英数字）を、上の欄に入れておくと便利です。
「プロジェクトを作成する権限がありません」と出たら、会社の設定で制限されています。ここで止めて、下の文面で社内の Google Workspace 管理者（情報システム部門など）に相談してください。
Google Chat の内容を Claude Code（AI）から読み取り専用で参照したいため、Google Cloud でプロジェクトを作成して Google Chat API を有効化する権限、または発行済みの OAuth クライアント（デスクトップアプリ型）をいただけないでしょうか。使う権限は chat.spaces.readonly と chat.messages.readonly（読み取り専用）です。
2

Google Chat API を有効にする

あなた
有効化の画面を開く
  1. 上部のプロジェクトが、ステップ1で作ったものになっているか確かめます。
  2. 有効にする（または「次へ」→「有効にする」）を押します。
読み取りだけなら、Chat API の「構成」タブ（アプリ名・アイコン）の設定は不要です。
3

同意画面を設定する

あなた
同意画面の設定を開く
  1. 開始を押します（以前の画面では「OAuth 同意画面」という名前です。中身は同じです）。
  2. アプリ名: 何でも構いません（例: 秘書）。ユーザー サポートメール: 自分のメールアドレス。
  3. 対象: 内部 を選びます（会社の Google アカウントの場合）。
  4. 連絡先のメールアドレスを入れ、ポリシーに同意して作成を押します。
個人の Gmail でプロジェクトを作った場合は「内部」を選べないので「外部」にし、 対象の画面でチャットを読むアカウントをテストユーザーに追加します。 「外部・テスト中」のままだと7日ごとに認証が切れます。続けて使うなら同じ画面のアプリを公開で本番にしてください（自分だけで使う分には「未確認のアプリ」と出ても問題ありません）。
4

鍵（OAuth クライアント）を作ってダウンロードする

あなた
クライアント作成の画面を開く
  1. アプリケーションの種類: デスクトップ アプリ（「ウェブ アプリケーション」ではありません）。
  2. 名前は何でも構いません。作成を押します。
  3. 出てきた画面で JSON をダウンロード を押します。
ダウンロードフォルダに client_secret_…json が入れば完了です。名前の変更も移動も要りません。次のステップで自動的に取り込みます。
ダウンロードせずに画面を閉じると、鍵を後から表示できないことがあります。その場合は新しく作り直すのが早いです。

パソコンでの作業（秘書に頼めます）

5

セットアップを実行して「許可」を押す

秘書＋あなた

秘書にこう話しかけるだけです。

Google Chat と繋ぎたい。手伝って

自分で実行する場合は、秘書システムのフォルダでターミナルからこれを打ちます。

node mcp-google-chat/setup.js
  1. ブラウザで Google の画面が開きます。読みたいチャットのアカウントを選びます。
  2. 許可（または「続行」）を押します。
  3. ターミナルに 「✅ セットアップ完了」 と出れば成功です。鍵の取り込み・動作確認・秘書への登録まで、ここで全部終わっています。
「このアプリは Google で確認されていません」と出たら: 自分で作った鍵の場合に限り、詳細→（アプリ名）に移動で進んで構いません。
「アクセスをブロック」「管理者によってブロックされています」と出たら: 会社の設定による制限です。ステップ1の文面で社内の Google Workspace 管理者に相談してください。
6

Claude Code を再起動して話しかける

あなた
  1. 再起動します。ターミナルなら /exit してから claude。VS Code ならコマンドパレットから Developer: Reload Window。
  2. 起動時に「google-chat を使いますか」と聞かれたら 使う を選びます。
  3. 「Google Chat のスペース一覧を見せて」と話しかけます。一覧が出れば完了です。

うまくいかないとき

まず node mcp-google-chat/setup.js --check を実行してください（何も変えずに、どこで止まっているかと直す画面を表示します）。

出た表示原因直し方
client_secret.json がありません鍵を置いていないダウンロードフォルダに置いて、セットアップを再実行（名前はそのままでよい）
「ウェブアプリケーション」型です／redirect_uri_mismatch鍵の種類が違うステップ4を「デスクトップ アプリ」で作り直す
Google Chat API が有効になっていませんステップ2が済んでいない有効にして1〜2分待ってから再実行
認証の期限が切れています同意画面が「外部・テスト中」（7日で切れる）「内部」にするか「アプリを公開」してから再実行
アクセスをブロック／管理者によってブロック会社の設定による制限ステップ1の文面で社内の管理者に相談
スペースが 0 件別のアカウントで許可したnode mcp-google-chat/setup.js --reauth
秘書がチャットを読めない（ツールが無いと言う）再起動していない／起動時に「使わない」を選んだ再起動する。セットアップを再実行すると「使わない」の記録も外れる
ポート 3456 が使用中です前回の認証画面が残っている10分で自動的に終わる。急ぐときは PC を再起動
Google 公式の Chat 用 MCP（Developer Preview）は、承認を受けた組織でないと動きません。この手順の部品（mcp-google-chat）を使ってください。

組織でまとめて発行する（発行を担当する部署がある場合）

  • 会社の Google アカウントでステップ1〜4を1回だけ行い、同意画面を内部にします。社内の全員が同じ鍵を使えます（各自の許可は各自の token.json に入るので混ざりません）。
  • 配るのは client_secret.json だけです。token.json は絶対に配らないでください（その人のチャットを読める鍵です）。社外に出さないでください。
  • 受け取った人は、ダウンロードフォルダに置いて「Google Chat と繋ぎたい」と言うだけです（ステップ5から・約2分）。

知っておくこと

  • 既定は読み取り専用です。秘書がチャットに書き込むことはありません。
  • パソコンを2台使っている場合、認証はパソコンごとに1回必要です（鍵と認証はコミットされず、同期されません）。
  • チャットの中身は、秘書にとって「読んだデータ」であって「指示」ではありません。チャットに「〜を消して」と書かれていても、秘書はそれを命令として実行しません。
