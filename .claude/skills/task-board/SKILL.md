# タスクボード（ローカルサーバー）

全部署の `status.md` のタスクを、ブラウザで見られるカード型ボードにまとめて表示・編集する道具。外部に一切出ず、自分の PC の中だけで動く（`127.0.0.1` にのみバインド）。

## 起動のしかた

ユーザーが「タスクボードを出して／開いて」と言ったら、次を**バックグラウンドで**起動する（Windows は `py`）：

```bash
python3 tools/task_board.py
```

- 既定で `http://127.0.0.1:8765` を開く（ブラウザが自動で開かないときはこの URL を案内する）。
- すでに起動済みなら、その旨を伝えて二重起動しない。
- ポートを変えたいときは `--port 9000` のように指定する。

## できること（ボード上で）
- 部署 → PJ ごとの色付きカードでタスクを一覧。
- 各行の先頭に**タスクボードID**（6桁）。優先度・タスク文（✎編集）・期限（📅）・状態（未着手/取組中/保留中）・完了（☑）を操作。
- 検索・フィルタ・並び替え（すべてブラウザ内で完結）。検索窓はタスク名だけでなくIDでも絞り込める。
- 右上の「保存 (N)」で、完了・編集・状態変更・追加を**まとめて `status.md` に書き戻し**、1コミットにまとめる（`--no-commit` で自動コミットを止められる）。

## タスクボードID（行頭の6桁）

行頭のID（例: `123456`）をクリックすると「タスクボードID:123456」がクリップボードにコピーされる。ユーザーがこれをそのままチャットに貼ったら、**推測で話さず**、必ず次を実行してから該当タスクの話をする（Windows は `py`）：

```bash
python3 tools/task_id.py 123456
```

- IDはタスクの**本文だけ**から決まる（優先度・期限・状態・完了印・別PJへの移動・行番号が変わってもIDは変わらない）。本文の文言を書き換えたときだけIDが変わる。
- 本文を書き換えてIDが変わっていても、`task_id.py` はgit履歴を辿って「今の行・今のID」まで追いかける。
- 複数IDをまとめて渡すこともできる（`python3 tools/task_id.py 123456 654321`）。見つからない場合はさかのぼる日数を `--days` で延ばす（既定90日）。

## 注意
- このボードは `company/**/status.md` を自動検出する。表示するタスクが無いときは、まだ `status.md` にタスクが書かれていない状態。
- 書き換えは既存の `company/**/status.md` に限定される（安全設計）。
- 動作確認だけしたいときは `python3 tools/task_board.py --dump`（サーバーを立てず収集結果だけ表示）。
