# mcp-google-sheets（Google スプレッドシート MCP サーバー）

Claude Code から Google スプレッドシートの中身を**読める**ローカル MCP サーバー（書き込みは任意で有効化できる）。
売上表・管理簿・事業計画をコピペで貼り直さなくても、Claude が直接そのシートを見て数字を答えられるようになる。
**セルの値だけでなく数式そのもの（`=SUM(B2:B9)` 等）も読める**ので、「この数字はどう計算されているのか」を追える。

**依存パッケージはゼロ**（Node.js 18 以上の標準機能だけで動く）。`npm install` もネット接続も不要で、置いた時点で動く状態になっている。

残る作業は認証だけ。**秘書に「スプレッドシートと繋ぎたい、手伝って」と言えば手順を案内する**ので、この README を自力で読み進める必要はない。

> **`client_secret.json` が最初からこのフォルダに入っている場合**は、Google Cloud 側の作業（下記 A）は組織側で済んでいる。**B の `node auth.js` から始めればよい。**

> **Google 公式のリモート MCP（`sheetsmcp.googleapis.com`）は使わない。** スコープ・API有効化・同意すべてを正した状態でも全ツールが 403 を返す事例に当たったため、枯れた通常の Sheets API v4（`sheets.googleapis.com`）を直接叩く実装にしている。

## 公開ツール

| ツール | 種別 | 内容 |
| --- | --- | --- |
| `sheets_get_spreadsheet` | 読み取り | シート名・シートID・行列数などのメタデータ。**範囲を指定する前にシート名を知るために使う**（セルの値は返さない） |
| `sheets_get_values` | 読み取り | 指定範囲のセル。`renderOption: FORMULA` で**数式そのもの**、`UNFORMATTED_VALUE` で生の数値が返る |
| `sheets_update_values` | 書き込み | 指定範囲を上書き。**既定では公開されない**（読み取り専用として動く）。使うには `GS_ENABLE_WRITE=1` と書き込みスコープの**両方**が必要 |

## スコープと書き込みの二重ロック（既定は読み取り専用）

| | 既定 | 書き込みを使う場合 |
| --- | --- | --- |
| スコープ | `spreadsheets.readonly` | `spreadsheets`（`node auth.js --write` で取得） |
| `.mcp.json` の `env` | なし | `"env": { "GS_ENABLE_WRITE": "1" }` |

**書き込みは既定で二重に無効**。有効にするには次の2つを両方行う（片方だけでは書き込めない）。

1. `.mcp.json` のこのサーバーのエントリに `"env": { "GS_ENABLE_WRITE": "1" }` を追加する（無いとツール自体が公開されない）
2. `node mcp-google-sheets/auth.js --write` を実行して再同意する（`spreadsheets` スコープを取り直す）

過去に書き込みスコープで認証した `token.json` が残っていても、1 を入れない限り書き込みツールは現れない。
**スプレッドシートの上書きは取り消しが効かない**（Claude 側から Ctrl+Z はできない）。まず読み取りだけで運用し、書き込みが本当に必要になってから足すことを強く勧める。

有効にした場合も安全側の作りにしてある。

- 1回の書き込みは **5000セルまで**（取り違えたときの事故の規模を抑える）
- ツールの説明に「書き込む前に `sheets_get_values` で現在値を確認する」と明記してあるので、Claude は原則として現在値を読んでから書く
- Drive のスコープは要求しないので、**シートの削除・共有設定の変更はできない**（できるのはセルの読み書きだけ）

## セットアップ手順

### A. Google Cloud 側（初回のみ・ブラウザ作業）

1. [Google Cloud Console](https://console.cloud.google.com/) にログインし、**プロジェクトを新規作成**する（既存プロジェクトでもよい）。
2. 「APIとサービス」→「ライブラリ」で **Google Sheets API** を検索し、**有効にする**。
3. 「APIとサービス」→「OAuth 同意画面」を設定する（ユーザーの種類は組織内なら「内部」。外部の場合は自分をテストユーザーに追加する）。
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**。
   - アプリケーションの種類：**デスクトップアプリ**
5. 作成後に表示される **JSON をダウンロード**する。

> **`mcp-google-chat` を既に入れているなら、その `client_secret.json` を使い回せる。** 同じデスクトップクライアントで構わないので、A を丸ごと省略してコピーするだけでよい（要求するスコープはスクリプト側で分かれている）。ただし Sheets API の有効化（手順2）は別途必要。

### B. このフォルダ側（初回のみ・ターミナル作業）

1. ダウンロードした JSON を **`client_secret.json`** という名前でこのフォルダに置く（すでに入っている場合はこの手順は不要）。
2. 認証する（Node.js 18 以上が必要。Windows でも `node` はそのまま使える。**`npm install` は不要**）：

   ```bash
   node mcp-google-sheets/auth.js
   ```

   ブラウザが自動で開く（開かない場合は表示された URL を手動で開く）。**読みたいスプレッドシートが入っているアカウント**で許可する。
   ターミナルに「token.json を保存しました」と出れば完了。
   SSH 越しなど自動で開かせたくない場合は `GS_NO_BROWSER=1` を付けて実行する。

3. プロジェクト直下の `.mcp.json` にサーバーを登録する（無ければ作る）：

   ```json
   {
     "mcpServers": {
       "google-sheets": {
         "command": "node",
         "args": ["mcp-google-sheets/index.js"]
       }
     }
   }
   ```

4. **Claude Code を再起動**し、シートのURLを貼って「このシートのシート名を一覧して」と頼んで動作を確認する。

## 秘密情報の扱い（重要）

- `client_secret.json` と `token.json` は**認証情報そのもの**。`.gitignore` に必ず追加し、リポジトリにコミットしない。
- ファイルは `0600` で書くが、**Windows ではこの権限指定は効かない**（ACLは変わらない）。同じPCの他ユーザーからは読めるので、PC自体のログイン保護で守ること。
- git で複数台のPCを同期している場合、**この2つは同期されない**（＝各PCで認証を1回ずつ行う必要がある）。共有されるのはコード（`index.js` / `auth.js` / `package.json`）だけ。
- 認証情報を他人に渡さない。渡すとそのアカウントで見られるスプレッドシートがすべて読める状態になる。

## 構成

- `index.js` … MCP サーバー本体（stdio・JSON-RPC を直接実装）。認証情報はこのファイルからの相対パスで読むため、実行時のカレントディレクトリに依存しない
- `auth.js` … 初回 OAuth 認証（PKCE + `state` 検証。`http://127.0.0.1:3457` を**ループバックのみで**待ち受けてリダイレクトを受信する。10分で自動終了）
- `package.json` … `type: module` の宣言のみ。**dependencies は無い**
- ポート 3457 が使われている場合は `auth.js` の `PORT` を変更して再実行する（3456 は `mcp-google-chat` が使う）
- **認証が未完了でもサーバーは正常に起動する。** ツールを呼んだときに「何をすればよいか」を返す設計（起動時に落とすと MCP の接続エラーになるだけで理由が伝わらないため）

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| `client_secret.json が見つかりません` | ファイル名が正確か（`client_secret (1).json` などになっていないか）・置き場所がこのフォルダか |
| ブラウザで「このアプリは確認されていません」 | 自分が作ったクライアントなので「詳細」→続行で進んでよい。外部種別ならテストユーザーに自分を追加 |
| API が 403 `PERMISSION_DENIED` | ①Google Cloud で **Sheets API が有効か** ②`token.json` のスコープが足りているか（書き込みは `--write` が必要） ③[アカウントのアクセス権画面](https://myaccount.google.com/permissions)で**実際に付与された権限を直接見る**（エラー文から逆算しない） |
| 404 が返る | `spreadsheetId` が URL の `/d/` と `/edit` の間の文字列になっているか。そのシートを開く権限が自分にあるか |
| 400 が返る | `range` のA1記法。シート名が実在するかは `sheets_get_spreadsheet` で確認する |
| 認証は通るが空のシートしか見えない | 許可したアカウントを間違えている可能性。`token.json` を削除して `node auth.js` をやり直す |
| Claude Code にツールが出てこない | `.mcp.json` の登録内容とパス、そして**再起動**したか。**エディタ拡張で使っている場合はエディタ自体を開き直す**（セッションを新しくするだけでは、起動済みのMCPホストが使い回されてツールが増えないことがある） |
| `Node.js 18 以上が必要です` と出る | `node --version` を確認する。18 未満なら Node.js を更新する（このサーバーは標準の `fetch` を使う） |
| `sheets_update_values` が出てこない／失敗する | 既定で無効。`GS_ENABLE_WRITE=1` と `node auth.js --write` の**両方**が必要（上記） |
